# 周期数据列表（开发版 API）

用于重复发送预先定义的数据序列，例如模拟设备状态依次变化。
此功能已接入源码后端及发送页控件；页面交互验证及便携版发布尚未完成。

通过 `POST /api/senders` 创建任务：

```json
{
  "name": "状态循环",
  "id": "123",
  "extended": false,
  "period_ms": 100,
  "auto_start": false,
  "mode": "list",
  "data_list": ["1234", "AB", ""]
}
```

- 每个周期发送一项；到达列表末尾后回到首项。示例依次发送 `12 34`、`AB`、零字节数据帧。
- 每项必须是合法十六进制字符串，允许空格，长度为 0～8 字节；整个列表不能为空。
- 列表内各项允许不同 DLC，ID 和标准/扩展帧设置沿用任务配置。
- 使用现有 `/api/senders/{id}/start`、`/stop` 控制启停。每次启动从第一项开始。
- 运行中通过 `PUT /api/senders/{id}` 修改 `data_list`，下一周期使用新列表，并按本次启动已发送次数对新列表长度取余选择数据项。
- 无效修改返回 400，保留修改前的任务配置。
- 复制任务与保存/读取配置现场会保留列表，副本默认停止。

回归测试：`tests/test_sender_list.py`，覆盖独立 virtual 接收端的数据顺序和标准帧标志、停止及重启、非法修改、API 复制和配置往返。

## 随机与掩码随机

同一个 API 使用 `mode: "random"`，以 `data` 确定 DLC 和不随机化的基础位：

```json
{
  "name": "随机低四位",
  "id": "123",
  "extended": false,
  "data": "AABB",
  "period_ms": 100,
  "auto_start": false,
  "mode": "random",
  "random_seed": 42,
  "random_mask": "0F00"
}
```

掩码中 1 表示该位随机化，0 表示保留基础数据位。例中首字节在 A0～AF 之间变化，第二字节始终为 BB。
掩码留空表示全部数据位随机化；非空掩码必须与数据长度相同。全零掩码保留全部数据。
种子必须为整数，默认 0。同版本中，相同配置和种子在每次启动时产生相同序列；每次启动的序号从 0 重新计数。
生成器针对每一帧使用 `random.Random("种子:序号")`，因此并行任务不会互相改变随机序列。

## 有界斜坡

使用 `mode: "ramp"`，通过现有 `inc_byte`、`inc_end` 选择小端无符号字节区间，`inc_step` 设置步长，`ramp_min`、`ramp_max` 设置上下限。
区间外的字节沿用 `data`；默认上下限为 0、255。范围必须可由所选字节数表示。

- 正步长从下限开始，负步长从上限开始；到下一步会超出范围时回到起点。
- 例如范围 254～259、步长 2，序列为 `254, 256, 258, 254, …`；步长 -2 时为 `259, 257, 255, 259, …`。
- 若步长不能整除范围，不额外插入边界值；步长大于整个范围时每次输出起点。
- 步长不允许为 0；上下限相等允许用于固定边界测试。

随机和斜坡参数均随任务复制和配置现场保存恢复；在线修改下一周期生效，继续沿用本次启动的序号。
相关回归测试为 `tests/test_sender_generators.py`。
